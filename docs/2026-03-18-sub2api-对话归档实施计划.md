# sub2api 对话归档实施计划

> 已废弃（2026-03-19）。
> 当前仓库不再按本计划实现外置 Python `archive_proxy`。
> 请以 `docs/2026-03-19-sub2api-会话归档部署说明.md` 和 `docs/superpowers/plans/2026-03-19-sub2api-session-turn-archive-patch.md` 为准。

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 增加一个独立的 Python 归档代理，置于 `Nginx` 与 `sub2api` 之间，只归档 Codex 与 Claude Code 的真实对话流量，不修改 `sub2api` 源码。

**Architecture:** 新增一个监听 `127.0.0.1:18080` 的 `aiohttp` 代理服务，负责筛选目标路径、归档请求与响应、透传 SSE，并对 WebSocket Upgrade 先做无损透传。部署侧补充 `systemd` 样例和 `Nginx` 配置片段，保持 `/v2ray` 现有链路不变。

**Tech Stack:** Python 3.11+, `aiohttp`, `pytest`, `pytest-asyncio`, systemd, Nginx

import pytest
from aiohttp import web, WSMsgType

from archive_proxy.app import create_app


@pytest.mark.asyncio
async def test_websocket_upgrade_passthrough(aiohttp_client, aiohttp_server):
    async def ws_handler(request):
        ws = web.WebSocketResponse()
        await ws.prepare(request)
        msg = await ws.receive()
        if msg.type == WSMsgType.TEXT:
            await ws.send_str(f"echo:{msg.data}")
        await ws.close()
        return ws

    upstream = web.Application()
    upstream.router.add_get("/responses", ws_handler)
    upstream_server = await aiohttp_server(upstream)

    app = create_app(upstream_base_url=str(upstream_server.make_url("")))
    client = await aiohttp_client(app)

    ws = await client.ws_connect("/responses")
    await ws.send_str("ping")
    msg = await ws.receive()
    assert msg.data == "echo:ping"
